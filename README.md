## Overview

A high-performance personal portfolio website inspired by Swiss editorial and neo-brutalist design principles. Built with clean vanilla web technologies, high-DPI HTML5 Canvas animation, Lenis momentum smooth scrolling, and responsive modular architecture.

### Key Highlights
- **Interactive Video Frame Engine**: 240 high-resolution frames rendered via an HTML5 Canvas, seamlessly interpolating with mouse scrub and scroll velocity.
- **Lenis Momentum Physics**: Butter-smooth inertial scrolling across mouse wheel, trackpad, and keyboard interactions.
- **Swiss Editorial Aesthetic**: Precise 1px grid layout, high-contrast typography, minimalist custom scrollbar, and header reading progress indicator.
- **Selected Project Showcase**:
  - **Fleet Intelligence System** (Caterpillar Hackathon Winner)
  - **ReachWise** (28-Test Deterministic Appointment Reminder Engine)
  - **BrightBud** (THREX Hackathon Top 15 AI Learning Platform)
  - **Crowd Tracker Pro** (Real-Time Transit & SOS Web App)
- **Direct Interactive Modals**: Detailed architectural breakdowns, technical specifications, and direct GitHub repository links.
- **Instant Communication**: Single-click email/phone clipboard actions, Chennai geolocation (`13.0827° N · 80.2707° E`), and message submission preview.

---

## Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript (ES6+), HTML5 Canvas
- **Libraries**: [Lenis](https://lenis.darkroom.engineering/) (Smooth Scroll), [Lucide Icons](https://lucide.dev/)
- **Typography**: Bebas Neue, Syne, Space Mono, Caveat, Inter
- **Backend / Server**: Lightweight Node.js static HTTP server with zero external dependencies

## Running Locally

Clone the repository and start the built-in server:

```bash
# Clone repository
git clone https://github.com/Yashwanths-hub/portfolio-website.git
cd portfolio-website

# Start local development server
node server.js
```

Open your browser and navigate to:
```
http://localhost:3000
```
